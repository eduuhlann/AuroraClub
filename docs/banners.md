# Banners AuroraClub

Quatro fotografias criadas com a ferramenta integrada `image_gen` para a identidade editorial do AuroraClub. Os PNGs são os originais; o site carrega cópias WebP otimizadas, sem texto embutido. Os títulos e chamadas são HTML. O banner principal recebe apresentação em preto e branco por CSS.

| Uso | Arquivo em `public/images/banners/` | Dimensões |
| --- | --- | --- |
| Principal desktop | `auroraclub-campaign-hero.png` / `.webp` | 1942 × 809 |
| Principal celular | `auroraclub-campaign-hero-mobile.png` / `.webp` | 1086 × 1448 |
| Campanha oversized | `auroraclub-campaign-oversized.png` / `.webp` | 1536 × 1024 |
| Campanha baby look | `auroraclub-campaign-baby-look.png` / `.webp` | 1536 × 1024 |

A composição vertical é selecionada pelo elemento `picture` até 760 px. A galeria usa uma coluna em telas pequenas. As fotos do editor e do catálogo continuam usando o atlas próprio, com as máscaras calibradas.
